# คู่มือใช้งานระบบหลังบ้าน MONSTOPIA

เอกสารนี้อธิบายการใช้งานสำหรับผู้เริ่มต้น โดยไม่จำเป็นต้องแก้โค้ดเว็บไซต์

## 1. เปิดระบบบนเครื่อง

เปิด PowerShell ที่โฟลเดอร์โครงการแล้วใช้คำสั่ง:

```powershell
D:\motopia\.runtime\php\php.exe artisan serve
```

จากนั้นเปิด:

- เว็บไซต์บริษัท: `http://127.0.0.1:8000`
- ระบบหลังบ้าน: `http://127.0.0.1:8000/workspace`

หน้าต่าง PowerShell ต้องเปิดค้างไว้ระหว่างใช้งาน ถ้าปิดหน้าต่าง เว็บบนเครื่องจะหยุดทำงาน

## 2. สร้างบัญชีผู้ดูแลครั้งแรก

ถ้ายังไม่มีบัญชี ให้หยุดเซิร์ฟเวอร์ด้วย `Ctrl+C` แล้วใช้คำสั่ง:

```powershell
D:\motopia\.runtime\php\php.exe artisan monstopia:create-admin
```

ระบบจะถามชื่อ อีเมล เบอร์โทร และรหัสผ่าน รหัสผ่านควรยาวอย่างน้อย 12 ตัวอักษร จากนั้นเปิดเซิร์ฟเวอร์อีกครั้งและเข้าสู่ระบบที่ `/workspace`

## 3. ความหมายของ CRUD

- Create: กดปุ่ม “เพิ่ม” หรือ “เขียนบทความ” เพื่อสร้างข้อมูล
- Read: เปิดแต่ละเมนูเพื่อดูข้อมูลที่บันทึกไว้
- Update: กด “แก้ไข” แล้วบันทึกข้อมูลใหม่
- Delete: กด “ลบ” และยืนยันก่อนนำข้อมูลออก

## 4. เมนูที่ใช้บ่อย

- ภาพรวม: ดูจำนวนโครงการ บรีฟ บริการ แพ็กเกจ ผลงาน และข่าวสาร
- ข้อมูลบริษัท: แก้ชื่อ คำแนะนำ อีเมล ที่อยู่ และเลขทะเบียน
- บริการ: จัดการรายการบริการ โดย `Slug` ใช้ตัวอักษรอังกฤษ ตัวเลข และเครื่องหมายขีดกลาง เช่น `web-application`
- แพ็กเกจ: กำหนดราคา ระยะเวลา สิ่งที่ได้รับ และเลือกแพ็กเกจแนะนำ
- ผลงาน: เพิ่มภาพหน้าจอจริง ชื่อโครงการ รายละเอียด และเทคโนโลยี
- ข่าวสาร: บันทึกเป็นฉบับร่างก่อน แล้วเปลี่ยนสถานะเป็นเผยแพร่เมื่อพร้อม
- บรีฟลูกค้า: อ่านรายละเอียด เปลี่ยนสถานะ และตอบกลับ
- ผู้ใช้งาน: Administrator สร้าง แก้ไข และลบบัญชีตามบทบาท

## 5. การเผยแพร่ข้อมูล

ข้อมูลที่ตั้งค่าเป็น “เผยแพร่” จะปรากฏบนหน้าเว็บไซต์หลังบันทึกและโหลดหน้าใหม่ ข้อมูลที่ตั้งค่าเป็น “ซ่อน” หรือบทความสถานะ “ฉบับร่าง” จะเห็นเฉพาะในระบบหลังบ้าน

## 6. ก่อนใช้งานจริงบนอินเทอร์เน็ต

ต้องใช้โฮสต์ที่รองรับ PHP/Laravel และ MySQL ตั้งค่า HTTPS, `APP_DEBUG=false`, อีเมล และ LINE Messaging API ห้ามนำไฟล์ `.env` หรือรหัสผ่านขึ้นพื้นที่สาธารณะ
